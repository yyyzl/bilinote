# BiNote v0.5.3

## 修复 Android 覆盖升级

- 找回并沿用实际 0.4.1 / 0.3.0 APK 的原签名密钥，新包可接续这些历史版本覆盖升级。
- 原签名已固定到 GitHub Actions。密钥缺失、证书不匹配或出现额外签名者时立即停止，禁止临时换钥发布。
- 校验兼容 Android SDK 36 / 37 的证书输出格式，继续严格要求与原证书一致。
- Android 安装包为 `BiNote_0.5.3_arm64.apk`。包名和笔记存储路径保持一致，无需迁移笔记。

## 升级方式

已安装原签名 0.4.1 / 0.3.0 的用户，直接打开 APK 并选择更新。**不要先卸载旧应用，也不要清除应用数据。**

如果曾安装其他云端临时签名包，Android 可能仍提示签名不一致；请保留旧应用及数据，先核对证书，不要通过卸载绕过限制。

## 验证

签名契约 8 类回归、实际 SDK 36 / 37 工具核验通过；23 项 Rust 单测和前端生产构建通过。在隔离 Android 36 环境中，安装真实 0.4.1 后验证同签名覆盖升级，应用 UID、首次安装时间、两条旧格式笔记及设置文件 SHA256 均保持一致，真实 Android 应用能读取旧笔记。用户手机未连接，不将模拟器验收描述为原手机实测。
