# BiNote v0.5.2

## 修复 Android 覆盖升级

- 找回并沿用实际 0.4.1 / 0.3.0 APK 的原签名密钥，新包可接续这些历史版本覆盖升级。
- 将原签名固定到 GitHub Actions，并核验证书指纹；密钥缺失或证书不匹配时立即失败，禁止自动生成临时密钥发布。
- Android 安装包为 `BiNote_0.5.2_arm64.apk`。保留原包名和笔记存储路径，无需卸载旧应用或迁移笔记。

## 升级方式

已安装原签名 0.4.1 / 0.3.0 的用户，直接打开 APK 并选择更新。**不要先卸载旧应用，也不要清除应用数据。**

如果曾安装其他云端临时签名包，Android 可能仍提示签名不一致；请保留旧应用及数据，先核对证书，不要通过卸载绕过限制。

## 验证

签名契约的 5 类回归、23 项 Rust 单元测试和前端生产构建通过。在隔离 Android 36 环境中，从真实 0.4.1 APK 验证同签名覆盖安装，应用 UID、首次安装时间、两条旧格式笔记及设置文件的 SHA256 均保持一致，并已保留校验备份。用户手机未连接，不将模拟器验证描述为原手机实测。
