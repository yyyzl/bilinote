# BiNote v0.6.0

新增自定义总结模板：为课程复习、快速阅读或编程教程准备不同的总结要求，再选择一个全局默认。

## 更新内容

- 在「设置 → AI 笔记生成 → 管理模板」新建、编辑或删除命名模板。
- 内置「标准笔记」保留原有总结格式，只读且可创建副本。
- 正在编辑的模板与默认模板相互独立；自动和手动总结使用保存的全局默认，API 与桌面 Codex 保持一致。
- 统一保存设置，支持校验、删除确认、失败重试；切换模板、返回设置和账号刷新保留未保存草稿。
- 桌面使用模板库与编辑器，手机使用「正在编辑」选择器；最多保存 50 个自定义模板。
- 保存过程中继续编辑，不会被迟到的保存结果覆盖；已接受的任务保留当时的模板。
- 已有笔记不会自动重写；思维导图与总结/内容预览的单次响应契约保持不变。

## 使用方法

1. 打开「设置 → AI 笔记生成 → 管理模板」。
2. 新建模板或复制内置模板，填写名称和 Markdown 总结要求。
3. 在「默认总结模板」中选择要使用的模板，然后点击「保存设置」。
4. 后续自动生成或显式重新生成总结时生效。标题和转录由应用带入，无需占位符。
