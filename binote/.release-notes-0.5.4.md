# BiNote v0.5.4

这次更新为 BiNote 换上了「电视笔记小幽灵」图标：亮蓝屏幕、深蓝轮廓和暖白纸页，把视频与笔记融进同一个角色。

## 更新内容

- 更新应用图标，保留小电视天线、幽灵尾巴、笔记线和纸页折角。
- 统一 Windows、macOS、Android 安装包图标，以及应用顶栏和浏览器图标。
- 本次更新主要调整图标，视频转写、笔记生成和已有笔记存储方式保持不变。
