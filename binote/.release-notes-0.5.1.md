# BiNote v0.5.1

## 本次更新

- 重构为绿色笔记工作台：轻量顶栏、居中内容区，移除侧栏与手机底部导航。
- 任务在笔记库内直接展开/收起，保留进度、取消、失败重试和查看笔记，不再来回跳转导航。
- 笔记列表使用具体内容预览，无需视频封面；总结与预览由同一次模型请求生成，旧笔记无需迁移。
- 完整保留原来的总结提示词，包括章节、顺序、金句提取和转录质量警告；仅追加 JSON 返回格式与独立预览要求。API 与 Codex 一致，思维导图提示词未变。
- 阅读页提供 AI 总结、原始转录、思维导图三个标签；调整设置分组并完善加载、等待和失败恢复。
- 修复通知未点击时抢占页面、任务恢复期间重复启动、旧失败记录跨页重新出现、并行生成结果被迟到读取覆盖等问题。

## 安装包

- Windows x64：EXE 安装器、MSI。
- macOS：Universal DMG，支持 Apple Silicon 和 Intel。
- Android arm64：临时签名测试 APK。当前未配置持续发布签名，不能将此 APK 当作旧版的覆盖升级包；请保留旧应用及其数据。正式覆盖升级包仍需原发布签名。

## 验证范围

界面重构已通过 43 类离线界面、流程及竞态回归；本次提示词修正后，23 项 Rust 单元测试、严格类型检查与前端生产构建通过。新增完整原文回归，验证原始总结要求逐字保留及预览约束独立追加。发布构建覆盖 Windows、macOS、Android；云端构建不等于全部平台实机验收。
